## Project Overview

가족 공유 장바구니 PWA (Family Shared Shopping List PWA). Vanilla JS (no build tools), Supabase backend, Kakao OAuth, real-time collaboration via Supabase Realtime. Deployed on Vercel.

제품 요구사항: `docs/PRD.md`

## Commands

```bash
# Start local dev server (port 8765)
node server.js
# or
npm start

# Generate PWA icons from SVG
node gen-icons.js

# Run E2E tests (Playwright)
npx playwright test test.mjs
```

The local server maps `/` → `index.html` and `/mobile/` → `mobile/index.html`.

## Architecture

Two independent HTML entry points (no shared JS modules — all code is inline):

- **`index.html`** — Desktop/PWA entry point with full features (category tabs, share modal)
- **`mobile/index.html`** — Mobile-optimized PWA entry point

Both files connect directly to Supabase via CDN (`@supabase/supabase-js@2` from jsdelivr). No bundler, no transpilation.

### Backend (Supabase)

- **Project ID**: `ugowzkpuymwuqoqwkvfi`
- **Tables**: `lists`, `shopping_items`, `list_members`
- **Realtime**: Subscribes to channel `list-{listId}` for INSERT/UPDATE/DELETE on `shopping_items`
- **Auth**: Kakao OAuth primary; anonymous fallback with UUID-prefixed user IDs (`u_` + randomUUID)

### State Management

Single `s` state object in each HTML file. Persisted to localStorage (userId, userName, listId). No external state library.

### Auth & Init Flow

```
Page load → Check Supabase session → Check localStorage fallback
→ Kakao OAuth redirect handling (replaceState to clean URL)
→ findOrCreateList() or joinList(invite_code) from ?join= URL param
→ Load items → Subscribe to Realtime channel
```

### PWA (mobile/)

- `mobile/sw.js` — Service Worker for app shell caching; Supabase API calls always bypass cache
- `mobile/manifest.json` — App name "장바구니", theme `#2563eb`
- Icons generated by `gen-icons.js` via Node Canvas

### E2E Tests

`test.mjs` uses Playwright. Tests cover: anonymous login, add/check/delete items, real-time sync between two browser contexts, invite link joining.

## Deployment

- Vercel 배포 중. `package.json` + `server.js` 공존 구조이므로 `vercel.json` (`framework: null`, `outputDirectory: "."`) 필요
- 모바일 PWA URL: `https://shopping-listapp-lilac-chi.vercel.app/mobile/index.html`

## Key Conventions

- Both `index.html` and `mobile/index.html` must be kept in sync for shared features (item CRUD, Realtime, auth)
- Categories are hardcoded strings in Korean (e.g., `'채소'`, `'육류'`)
- Invite codes are stored in the `lists.invite_code` column; shared via URL `?join=CODE`
- RLS (Row Level Security) is enabled on Supabase — any schema changes must account for RLS policies
- PWA 아이콘(PNG) 교체 시 반드시 `git` 직접 커밋 사용. GitHub MCP `push_files` 툴은 바이너리를 텍스트로 저장해 파일이 깨짐
